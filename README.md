# schotter

## Week 1 Experiment

I ran the Schotter sketch and changed the `CHAOS` parameter from `1.0` to `2.0`.

When `CHAOS` was increased, the squares became more rotated and scattered, making the overall pattern look more chaotic.

- `sketch.py` — Python code used to generate the sketch.
